# Matheus_bedeschi
atividade 3 etapa
1. Deixe main.py e dados_sistema.txt na mesma pasta. O arquivo TXT sera criado quando os dados forem salvos pela primeira vez.
2. Abra o terminal nessa pasta.
3. Execute: O programa comeca vazio. Use o menu numerico para cadastrar produtos, pagamentos, historico e categorias. As opcoes 5 e 6 do menu principal salvam e carregam os dados.
   * Estruturas utilizadas: Lista, Pilha, Fila, Arvore, Arquivo.
   * Todos os dados ficam no mesmo arquivo.
   * O arquivo dados_sistema.txt nao precisa ser criado manualmente. Se ainda nao existir, o sistema informa que iniciara vazio.
